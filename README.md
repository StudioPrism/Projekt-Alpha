# Projekt Alpha9

Studio Prism's science-fiction FPS project, built in s&box with planned Lightstream integration.

## Fresh foundation

This is the post-reset repository structure. No gameplay code, scenes, assets, project descriptor, or working Lightstream integration is included yet. Create the new game project through the s&box editor before attempting to build or play.

Previous work is preserved on [PreReset-1](https://github.com/StudioPrism/Projekt-Alpha/tree/PreReset-1). The separate [InDev](https://github.com/StudioPrism/Projekt-Alpha/tree/InDev) controller prototype is retained unchanged.

## Branches

- `main`: reviewed, integrated work.
- `Dev`: active integration and development; starts from the same fresh foundation as main.
- `PreReset-1`: main snapshot before this reset; historical reference.
- `InDev`: older development prototype; historical reference.

Use short feature branches from Dev, integrate into Dev, then promote validated work to main. Treat the archive branches as reference; bring back selected work deliberately rather than merging the entire old prototype.
